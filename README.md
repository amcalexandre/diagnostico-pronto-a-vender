# Diagnóstico Pronto a Vender

Diagnóstico gratuito para proprietários: 30 critérios em seis áreas, resultado de 0 a 100 e classe de A a E.

- `index.html`: fonte da página.
- `docs/index.html`: versão publicada, gerada com `node build.js`.

A página não guarda nem envia dados. O visitante decide no fim se envia o resumo por WhatsApp.
